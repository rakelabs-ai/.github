## Meet Rake

Rake is an Artificial Firmware Engineer.

Hand Rake a board and the work gets done the way a firmware engineer does it: read the schematics and datasheets, write the code, build it, flash it, and debug it on the real hardware. Rake works on your hardware, whatever you build.
